Signals per row (plan G)

  • Top TOTAL banner: portfolio sum · vault/chain count · offline warnings — first-glance treasury health
  • Identity: flat square badge, 2-char monospace monogram (MA / TH / OP)
  • Status dot (vault health): ● signed < 30d · ● signed 30–90d ago · ● RPC/last attempt failed · ● never signed (cold)
  • Vault code: monospace, uppercase — maps to org naming (TRADING-HOT, OPS-RESERVE)
  • Environment tag: PROD / TESTNET in the accent color — eliminates wrong-env mistakes
  • Meta line: quorum · signers total · last signed — all three come from existing local data; no relay change needed
  • Balance: right-aligned monospace; tap •••••• to hide (over-the-shoulder defense)
  • No emoji in default path — still available as optional custom label

Behavior summary

  • Scope: only affects WalletGroupHeader in v1 — signing flow, settings layout, copy stay unchanged
  • Stored as UserDefaults key walletDisplayMode ∈ {.standard, .vault}
  • Default = .standard (existing behavior preserved)
  • Changing mode is purely visual — no data migration, no server call, instantaneous
  • Vault Mode unlocks two additional toggles: Hide balances · Environment tag
  • v2 could add onboarding question "Using this device personally or for your org?" to auto-select
